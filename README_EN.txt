ETS2 TUNER (BETA)  -  Quick guide
=================================
Note: this is an early beta version. There may still be bugs.
Make a backup of your profile before bigger changes.

REQUIREMENTS
- Python 3.8 or newer (https://www.python.org/downloads/, tick
  "Add python.exe to PATH" during installation). No extra packages needed.
- An extractor to unpack the game data. Recommended:
  https://github.com/sk-zk/Extractor/releases  ->  extractor.exe
  Simply put extractor.exe into this folder.

START
1. Double-click "Start.bat". Your browser opens with the tool.
   (Keep the black window open while using the tool.)
2. Switch the language at the top right (DE / EN).
3. On first start the settings open. Game folder and mod folder are
   detected automatically. Click "Extract game data".
4. Select truck -> select engine or transmission -> "+ New version".
5. Click the maps/values on the left and adjust them.
6. "Export mod" -> "Save to mod folder".
7. In game: Mod manager -> activate mod -> service shop -> engine/transmission.

NOTES
- Your work is saved automatically in "projekt.json".
- After a game update: Settings -> "Extract game data".
- Prices/unlock level/names: Settings -> "Show shop values".
- Only set fields under "Experimental (1.61+)" on ETS2 1.61+.
- Singleplayer only (not allowed on TruckersMP).
- Problems? Check game.log.txt in Documents\Euro Truck Simulator 2\.
